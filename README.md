# 🧇 Waffle Personality

## About
Waffle Personality is a quickly made web dev project to refine my web development skills which had been rusted and I kept the theme to waffles as I made this project for waffle ysws by hackclub, it is a quick intro about what waffles are written by me and a quick waffle personality test all code is written by me by reading docs on w3school

## How It Works
1. First page is the intro to waffles and has an image of a waffle and a button to switch to page 2
2. page two uses radio type input buttons to take ure answer of personality test
